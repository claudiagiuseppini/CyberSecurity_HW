# Cybersecurity & Cryptography — Homework Assignments

A collection of university coursework exploring fundamental concepts in **cryptography and cybersecurity**, from classical cryptanalysis to symmetric encryption, authenticated encryption, pseudorandom number generation, and secure two-party protocols.

The assignments combine theoretical concepts with hands-on implementations, experiments, and analysis of results. Each report documents the problem, the proposed approach, and the implementation and/or experimental findings.

## Assignments

| Homework | Topic | Overview |
| --- | --- | --- |
| **HW1** | Frequency Analysis & Substitution Cipher | Cryptanalysis of a substitution cipher using character-frequency analysis and iterative decryption in Python. |
| **HW2** | Symmetric Encryption Benchmarking | C/OpenSSL implementation of CBC-mode encryption and decryption, comparing AES, Camellia, and SM4 across different file sizes. |
| **HW3** | Encryption & Authentication Performance | Benchmarking AES-128-CTR + HMAC, ChaCha20 + HMAC, AES-128-GCM, and ChaCha20-Poly1305 using C and OpenSSL. |
| **HW5** | Cryptographically Secure Pseudorandom Number Generators | Python implementations of RSA-based and Blum–Blum–Shub generators, evaluated for execution time, output-bit balance, and state size. |
| **HW6** | Secure Rock–Paper–Scissors | A two-player network game using SHA-256 hash commitments and a reveal phase to protect hidden moves, implemented with Python, Flask, and Docker. |
| **HW7** | Fair Dice Game over a Network | A two-player dice game using a commit–reveal protocol and hash-derived outcomes, implemented with Python, Flask, and Docker. |
